# 几何深度学习 · 分组与每周成绩

网站：[打开课堂](https://ly633.github.io/GDL/)

学生在同一网址查看教师已发布的分组与每周个人成绩；教师使用密码登录后编辑和发布。

## 文本提交与在线汇总表

- 学生入口：`https://ly633.github.io/GDL/?view=submit`。填写姓名、学号和自由文本，无需 GitHub 账号。
- 教师入口：`https://ly633.github.io/GDL/?view=submissions`。使用现有教师密码查看全部提交、打开原文和导出 Excel。
- 每次最多 20,000 个 UTF-16 单位（大部分中文按一个字符，部分 emoji 按两个计数）；保留文本换行、Markdown、代码及前后空白，不执行 HTML。
- 成功后显示服务器回执与时间，可下载回执和原文。网络失败保留当前页面输入，原样重试使用相同提交编号以免重复保存；刷新或关闭页面不保留未提交内容。
- 同一学号再次提交会新增记录；不覆盖先前内容。姓名和学号为学生自填，目前不验证学生身份，不限制班级成员，不设置截止时间。
- 在线表格由现有后台的数据库保存，不同步到第三方表格产品；仅教师登录后可读取，学生提交内容不会写入公开 GitHub 仓库或课堂成绩 API。
- 表格每次加载 50 条，导出读取全部记录；分页与导出固定快照，新收到的提交点击刷新查看。Excel 保留学号前导零，并将文本存为字符串而非公式。
- 本地联调可在启动 Vite 前配置 `VITE_CLASSROOM_API_BASE` 指向测试 API。生产未配置时使用原教师后台地址。

## 教师登录

1. 首次通过交给教师的专用入口设置密码。入口有效期为 24 小时，完成后自动失效；不要把此设置链接分享给学生。
2. 密码至少 12 个字符，可使用较长短语；最多 72 个 UTF-8 字节。以后在任何设备打开网站，点击“教师登录”并输入该密码即可。
3. 登录会载入本机原有的名单与成绩草稿。换设备时载入线上版本；若草稿版本与线上不同，先选择继续本机草稿，或用线上版本替换。
4. 组队、评分后点击“发布”。显示成功后，学生刷新同一网址即可看到更新。
5. 登录后可“修改密码”。修改会让其他设备的旧登录失效。“退出”撤销当前会话。页面刷新后需重新登录。

密码由后台验证，不放在公开网页代码中，也不以明文保存在数据库中。页面不会保存密码或持久化登录令牌；有效会话最长 12 小时。学生没有教师注册入口，不能修改共享成绩。忘记密码时需由后台所有者协助恢复。

## 组队与评分

- 支持导入 `.xlsx`、`.xls`、`.csv`，可下载模板或粘贴姓名。导入时选择工作表、起始行、姓名列与可选学号列。
- 默认每队最多 3 人。10 人按 3 人分队：均衡模式为 3、3、2、2，保留尾队为 3、3、3、1。
- 选择作业后给小队填写总分，支持一位小数及快速加减 1 分。队伍总分 85 时，每位成员均记 85；改为 90 后同步更新为 90。
- 个人成绩表每行一位学生，每列一次作业。`—` 为未评分，`0` 为已评分 0 分，平均分只统计已评分作业。
- “添加作业”保留往周成绩，新作业沿用分组、成绩为空，也可重新分队。
- 重新分队保留个人成绩并重置本周小队分数；重新评分时更新新队伍成员。撤销恢复成员原成绩；清零仅影响所选作业。
- 替换名单或清空课堂会清除全部周成绩，会先确认。每周上课只需添加作业，不必重导名单。
- “导出”包含全部周个人成绩表、当前队伍排行、各周分组和本机计分记录。“分享”复制固定网站地址，“投屏”放大看板。

## 数据保存

- 网页仍由 GitHub Pages 托管。密码验证、共享数据及发布操作由独立的 Sites 后台提供，使用 Cloudflare D1 持久保存。课堂发布不再提交 GitHub 或等待网页重新部署。
- 未登录时只读取已发布数据，不读取浏览器草稿。教师草稿保存在当前浏览器，清理网站数据会丢失尚未发布的修改；重要记录请导出 Excel。
- Excel 原文件仅在浏览器解析。发布会公开姓名、学号、各周分组和个人成绩；原始文件名、计分备注和撤销历史留在本机。
- 后台校验每次写入的登录身份和数据。提交包含原版本编号，旧设备不能覆盖较新的发布；冲突或网络结果不确定时保留草稿，重新登录核对。
- 旧版本本机成绩仍自动迁移。旧 `#result=…` 链接仍能查看历史快照。
- 最多 500 人、100 次作业；每次导入限 10 MB、1000 行、100 列，空姓名跳过，同名保留，重复学号需修正。每周本机保留最近 2000 条计分记录；单次公开数据限 900,000 字节。
- 随机分组使用 Web Crypto 和 Fisher–Yates，每名学生恰好属于一队。

## 开发维护

需要 Node.js 24 或 >=22.13：

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

React + TypeScript + Vite，静态输出位于 `dist/`，支持 GitHub Pages 子路径。

- `app/app.tsx`：密码登录、首次设置、草稿选择、密码修改和发布。
- `app/page.tsx`：分队、评分和成绩表。
- `lib/publishing.ts`：后台 API 客户端、公开数据清理、本机草稿。
- `lib/classroom.ts`：分队、每周评分、校验与迁移。
- `lib/excel.ts`：Excel 解析和导出。
- `public/classroom.json`：旧版迁移数据，不再随发布更新。

教师后台在同一工作区的独立 `classroom-backend` 项目中，其部署和数据库由 Sites 管理。其源码包含密码哈希、会话撤销、一次性初始化、限流、来源检查及条件更新；不要把密码或初始化令牌写入前端仓库。数据库迁移已上线后只追加，不修改历史迁移。

GitHub Pages 的 Source 使用 **GitHub Actions**；推送网页代码到 `main` 后，由 `.github/workflows/pages.yml` 自动测试、构建并部署。日常课堂评分和发布不需要操作 GitHub。

Excel 使用打包到本站的 [SheetJS CE](https://docs.sheetjs.com/docs/getting-started/installation/frameworks/)，运行时不依赖外部 Excel CDN。
